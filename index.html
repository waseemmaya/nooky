Getting started

Up and running in a minute

 

Install and open

Move Nooky to Applications (or run the installer). It lives in your menu bar / tray, with no Dock icon.

Hover to open

Rest the pointer on the notch, or the top-centre handle. Click the tray icon for settings and quit.

Make it yours

Settings → Tabs lets you reorder and hide tabs; pick Glass or Classic; connect Vercel, GitHub or Claude Code if you want them.

FAQ

Questions, answered

 

Is Nooky free?

Yes. There's no account, trial or subscription.

Does it work without a notch?

Yes. On Macs without a notch, and on Windows and Linux, a small handle at the top-centre of the screen opens it the same way.

Which features are Mac-only?

The native frosted-glass blur, AirDrop, Quick Look, Apple Music, Calendar and Reminders integrations, the volume/brightness HUD and Keychain-backed tokens use macOS services. The rest — notes, clipboard history, tray, focus timer, teleprompter, deploys, screenshots, and your tabs — work everywhere.

Why does macOS say Nooky can't be opened?

Nooky isn't notarized by Apple yet. After moving it to Applications, run xattr -dr com.apple.quarantine /Applications/Nooky.app once, then open it.

What permissions does it ask for?

Only what a feature needs, when you first use it: Calendar and Automation (Music, Spotify, Finder), Camera (mirror), Microphone (teleprompter voice mode) and Screen Recording (screenshots).

Where is my data?

On your computer. Notes, clipboard history and settings stay in Nooky's local app data. Vercel and GitHub tokens go in the system keychain. Nooky doesn't send your data anywhere.

How do I update?

Download the latest build from this page and install it over the old one. Your settings are kept.
